# 💈 Navalha Nobre — Sistema de Gestão para Barbearia

Sistema de gerenciamento desenvolvido para facilitar a administração de barbearias, reunindo em um único painel o controle de agendamentos, clientes, profissionais, serviços, produtos e financeiro.

🔗 **Acesse o projeto:** https://adm-barbearia.vercel.app/

## 📸 Sobre o projeto

O Navalha Nobre foi desenvolvido com o objetivo de oferecer uma solução prática e organizada para o gerenciamento de uma barbearia, facilitando o acompanhamento dos atendimentos e o controle administrativo do negócio.

## 🚀 Funcionalidades

- **Agenda:** visualização e gerenciamento dos horários dos barbeiros.
- **Relatórios:** acompanhamento de atendimentos, faturamento, comissões e despesas.
- **Clientes:** cadastro e gerenciamento de clientes.
- **Clube Navalha:** gerenciamento de membros e pagamentos.
- **PDV e Produtos:** cadastro de produtos, controle de estoque e registro de vendas.
- **Contas a pagar:** gerenciamento de contas, parcelas e vencimentos.
- **Configurações:** cadastro de profissionais, serviços, horários de funcionamento e exceções.
- **Controle financeiro:** acompanhamento de entradas, saídas e resultado líquido.

## 🛠️ Tecnologias

As tecnologias utilizadas no projeto devem ser listadas conforme a implementação atual.

## 🎯 Objetivo

Criar uma ferramenta que ajude barbearias a organizar sua rotina, otimizar o gerenciamento dos atendimentos e ter maior controle sobre suas operações e resultados financeiros.
